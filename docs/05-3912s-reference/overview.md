# Vigor3912 Series (product page)

Source: https://www.draytek.com/products/vigor3912

10G High-Performance Router. Quad-Core 2GHz CPU. 8 WAN interfaces: 2x 10G SFP+, 2x 2.5G Ethernet, 4x 1G Ethernet; ports 1–8 independently switchable WAN/LAN; 4 fixed 1G LAN ports.

## Models

| Model | Memory |
|---|---|
| Vigor3912 | 8GB DDR4 |
| **Vigor3912S** | 8GB DDR4 + 256GB SSD |

## Key figures

- Up to 8 WANs; Quad-Core CPU provides **15.6 Gbps NAT throughput** (bi-directional).
- **500 VPN** tunnels; 5.7 Gbps IPsec throughput; 500 hosts; 2048 Bind-IP-to-MAC entries.
- 100 VLAN / LAN subnets; 200 PPPoE user accounts.
- 1000k NAT sessions.
- 2x USB 3.0; 1x RJ-45 Console; 1x Factory Reset button.

## Key features

- Quad-Core Processor; PPPoE Server; 10G SFP+; Hotspot Web Portal; Load Balancing; Bandwidth Management; VPN; Firewall & Content Filter; SSL VPN; EasyVPN; DrayDDNS; VPN 2FA for AD/LDAP; Central AP Management; VPN Matcher; Central Switch Management; Port Knocking; VRRP.
- Layer 3 Routing with BGP and OSPF.
- Packet Capture Tool (mirror to LAN port / download .pcap via WUI).
- Server Load Balancing.

## Linux Applications (3912S only)

- **VigorConnect** — Docker server on-device; install via WUI.
- **Suricata** — IDS/IPS, 60,000+ rules (6,000+ CVE), statistics, Smart Action notifications (Web/Telegram), auto-blocking.
- **Applications on Ubuntu** (armv8).

## Management (Local Service)

HTTP, HTTPS, Telnet, **SSH v2**, FTP, TR-069. Port Knocking for Local Service. Config Backup/Restore. Firmware upgrade via WUI, TFTP, TR-069. 2-Level Administration Privilege, Role-based Privilege. Access Control, Brute Force Protection. SNMP v1/v2c/v3, Syslog, Netflow.

## Physical

- Power: AC 100–240V @ 0.5–0.7A; max 35W.
- Dimensions: 443 x 285 x 45 mm.
- Operating temp 0–45°C; storage −10–55°C; humidity 10–90% non-condensing.
- Firmware at time of page: V4.3.5.1.
